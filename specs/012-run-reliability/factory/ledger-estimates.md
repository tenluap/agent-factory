# Usage estimate limitation

Harness-reported token usage is unavailable; all usage is word-count estimates, not billed usage.

Earlier orchestrator ledger estimates counted every declared changed output file, including generated dist and copied fixture artifacts, rather than limiting output-file word counts to this run's factory directory as state.md specifies. This overstates output estimates; it does not change deadlines, issue provenance, elapsed intervals or recorded check outcomes. Existing ledger records remain unchanged. Later output estimates use the specified factory-directory scope.

Read the totals usage clause with this limitation; no spending or performance claim is based on it.
